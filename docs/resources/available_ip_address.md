# netbox_available_ip_address (Resource)

Per [the docs](https://netbox.readthedocs.io/en/stable/models/ipam/ipaddress/):

> An IP address comprises a single host address (either IPv4 or IPv6) and its subnet mask. Its mask should match exactly how the IP address is configured on an interface in the real world.
> Like a prefix, an IP address can optionally be assigned to a VRF (otherwise, it will appear in the "global" table). IP addresses are automatically arranged under parent prefixes within their respective VRFs according to the IP hierarchya.
>
> Each IP address can also be assigned an operational status and a functional role. Statuses are hard-coded in NetBox and include the following:
> * Active
> * Reserved
> * Deprecated
> * DHCP
> * SLAAC (IPv6 Stateless Address Autoconfiguration)

This resource will retrieve the next available IP address from a given prefix or IP range (specified by ID)

## Example Usage
### Creating an IP in a prefix
```terraform
data "netbox_prefix" "test" {
  cidr = "10.0.0.0/24"
}

resource "netbox_available_ip_address" "test" {
  prefix_id = data.netbox_prefix.test.id
}
```

### Creating an IP in an IP range
```terraform
data "netbox_ip_range" "test" {
  start_address = "10.0.0.1/24"
  end_address   = "10.0.0.50/24"
}

resource "netbox_available_ip_address" "test" {
  ip_range_id = data.netbox_ip_range.test.id
}
```

### Marking an IP active and assigning to interface
```terraform
// Assumes Netbox already has a VM whos name matches 'dc-west-myvm-20'
data "netbox_virtual_machine" "myvm" {
  name_regex = "dc-west-myvm-20"
}

data "netbox_prefix" "test" {
  cidr = "10.0.0.0/24"
}

resource "netbox_interface" "myvm-eth0" {
  name               = "eth0"
  virtual_machine_id = data.netbox_virtual_machine.myvm.id
}

resource "netbox_available_ip_address" "myvm-ip" {
  prefix_id    = data.netbox_prefix.test.id
  status       = "active"
  interface_id = netbox_interface.myvm-eth0.id
}
```

## Schema

### Optional

- `comments` (String) Free-form comments about the available ip address.
- `custom_fields` (Map of String) Custom field values of the object, as a map of field name to value.
- `description` (String) A description of the available ip address.
- `device_interface_id` (Number) The ID of the device interface associated with the available ip address. Conflicts with `interface_id` and `virtual_machine_interface_id`.
- `dns_name` (String) The DNS name of the available ip address.
- `interface_id` (Number) The ID of the interface associated with the available ip address. Required when `object_type` is set.
- `ip_range_id` (Number) The ID of the ip range associated with the available ip address.
- `nat_inside_address_id` (Number) The ID of the nat inside address associated with the available ip address.
- `object_type` (String) Valid values are `virtualization.vminterface`, `dcim.interface` and `ipam.fhrpgroup`. Required when `interface_id` is set.
- `owner_id` (Number) The ID of the owner associated with the available ip address. Needs NetBox 4.5.0 or later.
- `prefix_id` (Number) The ID of the prefix associated with the available ip address.
- `role` (String) Valid values are `loopback`, `secondary`, `anycast`, `vip`, `vrrp`, `hsrp`, `glbp` and `carp`.
- `status` (String) Valid values are `active`, `reserved`, `deprecated`, `dhcp` and `slaac`.
- `tags` (Set of String) Tags assigned to the object, by name.
- `tenant_id` (Number) The ID of the tenant associated with the available ip address.
- `virtual_machine_interface_id` (Number) The ID of the virtual machine interface associated with the available ip address. Conflicts with `interface_id` and `device_interface_id`.
- `vrf_id` (Number) The ID of the vrf associated with the available ip address.
